```bash
cd personal_portfolio
```

```bash
index.html
```

# 🚀 Deployment

## GitHub Pages

1. Push your code to GitHub.

2. Open Repository Settings.

3. Navigate to

```
Pages
```

4. Select

```
Deploy from Branch
```

5. Choose

```
main
```

6. Save.

Your website will be available at

```
https://chandrakantkore.github.io/personal_portfolio/
```

---

## Deploy on Vercel

```bash
npm install -g vercel
```

```bash
vercel
```

---

## Deploy on Netlify

- Login to Netlify
- Click **New Site**
- Import Git Repository
- Deploy
